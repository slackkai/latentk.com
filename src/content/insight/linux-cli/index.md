终端吓人，是因为它什么都不显示。没有图标，没有「你确定吗」，光标停在那里，像在等你先认错。

其实它只认一件事：:mark[你现在站在哪个目录里]。几乎每条让人慌的命令——`rm` 删错东西、`ls` 说什么都没有——都是因为站错了地方。这份教程就从「站在哪」开始，七课，每课一个沙盒。沙盒是浏览器里的一台小电脑，上面铺着当前目录的文件卡片，你敲一条命令，卡片就变一次。

:::postit[怎么用沙盒]{tip}
任务里的命令点一下就填进终端。终端认 **Tab** 补全、**↑ ↓** 翻历史；上面的文件卡片点一下，会帮你填好 `cd` 或 `cat`。卡住了点「提示」，想重来点右上角「↺ 重来」。
:::

## 第 1 课：先问自己在哪

四个命令就够出门。

| 命令 | 它问的问题 |
| --- | --- |
| `pwd` | 我站在哪 |
| `ls` | 这里有什么 |
| `cd 目录` | 走进去 |
| `cat 文件` | 读给我听 |

`cd` 后面什么都不写，是回家；`cd ..` 是退回上一级；`cd -` 是回到上一次站的地方。`~` 是家目录的缩写，所以 `cd ~/文档/笔记` 不管你现在在哪，都能一次走到。

:::layout{wide}
::embed[第 1 课：在一间已经住了人的家里走一圈。]{page=./attachments/sandbox-1}
:::

路径分两种。:mark[绝对路径]从家门口写起，`~/文档/笔记`，换个地方站着结果一样。:mark[相对路径]从脚下写起，`笔记`，你站在 `文档` 里它才找得到。:note[迷路时不要继续敲。先 pwd，再 ls，确认自己站对了再走下一步。]

## 第 2 课：建一个属于你的角落

读完了就要写。终端写文件不靠「新建」按钮，靠两个箭头：

- `echo "一行字" > 文件`：:pen[覆盖]。文件没有就建，有就把原来的抹掉。
- `echo "又一行" >> 文件`：:pen[追加]{wavy}。接到末尾，原来的还在。

一个箭头和两个箭头只差一笔，后果差很多。拿不准的时候，先 `cat` 看看里面有什么。

:::layout{wide}
::embed[第 2 课：从空目录建出一个项目，再给它改名、复制备份、删掉备份。]{page=./attachments/sandbox-2}
:::

`mv` 一个人干两件事：目标是个新名字，它就是改名；目标是个已有的目录，它就是搬家。`cp` 留下原件，`rm` 不留。

:::postit[先看再删]{warn}
`rm` 没有回收站。沙盒里删了可以重来，你自己的电脑上不行。删之前用 `ls` 或 `cat` 确认那就是你要扔的东西。
:::

## 第 3 课：让 ls 把话说全

`ls` 默认很客气，只给名字。两个开关能让它多说：

- `-l` 长格式。每行开头那九个字符是权限，后面是大小和名字。
- `-a` 全部。把以 `.` 开头的隐藏文件也列出来。

两个可以叠成 `ls -la`。选项是同一把钥匙上的齿，不是另一条命令。

长文件不必整份读。`head -n 3 文件` 只要开头三行，`tail -n 3 文件` 只要结尾三行，`wc -l 文件` 告诉你一共多少行。

:::layout{wide}
::embed[第 3 课：一份四十行的日志、一个藏起来的文件。]{page=./attachments/sandbox-3}
:::

:pen[为什么配置文件总以点开头？]{hide} 不是为了保密。早期的 `ls` 要跳过 `.` 和 `..` 这两项，图省事就跳过了所有点开头的名字。隐藏是个副作用，后来变成了约定。

## 第 4 课：一个找文件，一个找行

东西一多，`ls` 就不够用了。两个命令分工很干净：

- `find . -name "*.md"` 按:mark[名字]找文件。`*` 是通配，代表这一截里随便什么字。
- `grep 番茄 菜谱/番茄蛋.md` 按:mark[内容]找行。加上 `-n`，它把行号也印出来。

`tree` 则是把目录画成一棵树，迷路之前先看地图。

:::layout{wide}
::embed[第 4 课：三份笔记散在菜谱和日记里，把提到番茄的找出来。]{page=./attachments/sandbox-4}
:::

:::fold[真终端里还能再进一步]
`grep -r 番茄 .` 会递归进每一个子目录，不用你一个个文件指给它。`-i` 忽略大小写。沙盒里一次只查一个文件，够把「找哪一行」这件事练熟。
:::

## 第 5 课：门锁是九个字符

`ls -l` 里的 `rwxr-xr-x` 拆成三段，每段三把钥匙：:mark[读 r]、:mark[写 w]、:mark[执行 x]。三段分别发给三个人：你自己、同组的人、其他所有人。

数字是钥匙的简写。读是 4，写是 2，执行是 1，一个人的权限把这三个数加起来：

| 数字 | 算式 | 意思 |
| --- | --- | --- |
| 7 | 4+2+1 | 读、写、执行 |
| 6 | 4+2 | 读、写 |
| 5 | 4+1 | 读、执行 |
| 4 | 4 | 只读 |
| 0 |  | 什么都不能 |

所以 `chmod 644 文件` 是「自己读写，别人只读」，`chmod 600 日记` 是「只有自己能碰」。不想算数的时候，用 `chmod +x 脚本` 给自己加上执行，`chmod -w 文件` 把自己的写权限拿掉。

脚本少了 `x`，系统就当它是一份普通文本，不肯运行。:note[权限拒绝几乎都是这一位的问题：目录要有 x 才能走进去，脚本要有 x 才能跑。]

## 第 6 课：一条命令只做一件事

终端好用，不是因为命令多，是因为每条都很小，而且能接起来。

- `>` 把一条命令的输出存进文件，而不是只在屏幕上闪一下。
- `&&` 把两步串成一句：前一步成功了，才做后一步。
- `|` 更进一步，把前一条的输出直接喂给后一条。`ls 来信 | wc -l` 就是「列出名字，然后数一数」。

沙盒里没有真正的管道，用 `>` 和 `&&` 把同样的想法走一遍。记住这个脾气就够了：:mark[每个工具做一件事，做完把结果交出来]。

不知道一条命令还能怎么用，问它自己：`man grep`。手册比搜索来的整段命令可靠，因为它说的是这一条，不是某一篇帖子里碰巧能跑的那一串。

## 第 7 课：手滑了

最后一个场景是一间已经乱掉的房间：过期的备份、一个临时目录、一份混进来的表格。清理的顺序比命令重要。

:::steps
1. 先看。`tree` 或 `ls -l`，确认你以为要删的东西真的在那。
2. 再确认。`cat` 读一遍，或者 `find . -name "*.bak"` 把目标圈出来。
3. 最后才动手。`rm` 删文件，`rm -r` 删目录——目录里面可能还有东西，所以必须多写一个 `-r`。
:::

:::layout{wide}
::embed[第 7 课：看清、删掉该删的、把表格挪去它该去的目录。]{page=./attachments/sandbox-7}
:::

:::postit[删目录之前多看一眼路径]{warn}
`rm -r` 会把目录和里面的一切一起拿走。命令写好后，先核对 `pwd` 印出来的位置，再按回车。
:::

## 一张可以回来查的表

| 想做的事 | 命令 |
| --- | --- |
| 我在哪 | `pwd` |
| 这里有什么 | `ls`，要详情加 `-l`，要隐藏文件加 `-a` |
| 走过去 | `cd 目录`，回家是 `cd`，后退是 `cd ..` |
| 读文件 | `cat 文件`，只要头尾用 `head` / `tail` |
| 建目录 | `mkdir 名字`，要连中间层一起建加 `-p` |
| 写一行 | `echo "字" > 文件`，追加用 `>>` |
| 复制 / 改名 / 删除 | `cp`、`mv`、`rm`，删目录加 `-r` |
| 按名字找 | `find . -name "*.md"` |
| 按内容找 | `grep 词 文件`，要行号加 `-n` |
| 改权限 | `chmod 644 文件`，或 `chmod +x 文件` |
| 看说明书 | `man 命令` |

不用背。忘了就回这一页，或者在沙盒里再敲一遍——重来是免费的。

## 接下来

沙盒把你关在家目录里，也没有管道和 `sudo`。这两样是故意留在外面的：一个要在真终端里体会「输出接输出」，一个要在你真的需要管理员权限时再学，而不是现在。

打开你自己的终端，从 `pwd` 开始，把第 2 课的项目在一个空目录里重新建一遍。
