# 资料快览与阅读工作台

## 资料库

- 点击卡片上的“快览”查看真实正文笔记、摘要、标签和来源链接。原来的标题仍直接进入详情页。
- 宽屏在右侧展开；窄屏在所选卡片下展开，可用“关闭快览”收起。
- 类型、Kai 的阅读状态、关键词与“只看我的稍后读”可以组合筛选。排序保留“最新 / 评分 / 在读优先”。
- 快览中的“加入稍后读”是访客自己的收藏，不改变 Kai 为资料设置的在读 / 已读状态。

## 文章阅读

所有内容详情页均提供稍后读、字号、行宽和专注模式。专注模式收起目录和文章底部的推荐区域；导航栏与阅读设置仍可操作。

阅读位置按文章记录。离开后重新打开时，若文章尚未读完，会显示“继续阅读”。点击可回到最近的章节及章节内位置；“从头阅读”清除该文章的进度。使用带章节锚点的链接进入时，优先定位该锚点，不显示续读提示。

## 稍后读入口与数据

导航栏的书签按钮打开统一的稍后读列表。资料快览与文章页共享收藏状态，刷新和切页后保留，也可以逐项移除。

收藏、进度和偏好保存在当前浏览器的 localStorage；不需要登录，不上传 GitHub，不同步其他设备。清理浏览器数据或切换域名会失去这份本地状态。浏览器禁止存储或空间不足时退回本次浏览内保存，并在页面提示。

收藏最多 200 项，满额后提示先移除一些，不会自动删除旧收藏；阅读进度保留最近 100 篇文章的记录。

## 验证

`npm test` 包括存储损坏恢复、不可用/配额耗尽、不同站点隔离、跨标签页写入合并和收藏路径校验。浏览器另外检查快览展开、组合筛选、收藏同步、续读、阅读设置持久化和手机布局。
